UNDERSTAND THE LOGIC

How does it work?

MUX

Multiplexer (MUX)

A multiplexer is a data selector. It selects one of many input lines and forwards the selected input to a single output.

Y = Dn, where n = (S2S1S0)2
  • 8 data inputs: D0–D7
  • 3 select lines: S2, S1, S0
  • 1 output: Y
DEMUX

Demultiplexer (DEMUX)

A demultiplexer is a data distributor. It routes one input to exactly one of several output lines, based on the select inputs.

Yn = D; all other outputs = 0
  • 1 data input: D
  • 3 select lines: S2, S1, S0
  • 8 outputs: Y0–Y7
Remember: With 3 select lines, the number of selectable channels is 2³ = 8.
